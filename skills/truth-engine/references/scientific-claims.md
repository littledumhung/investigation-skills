# 科學與醫療證據
先確認DOI、作者、版本、研究類型、全文或只有摘要、同行審查狀態、更正／撤稿紀錄。Crossref metadata只供發現，不保證全文、品質或最新撤稿狀態。預印本不得自行標成同行審查；期刊發表也不等於正確。

逐項擷取：研究問題／族群、對照、介入或暴露、結果指標、樣本數、追蹤期間、效果量與區間、隨機分派／盲法、失訪、混雜、多重比較、預先註冊、資金與利益衝突。比較作者原句與媒體主張的推論強度。

細胞／動物資料不能直接支持人體療效；觀察研究的相關性不直接支持因果；統計顯著不代表效果大或臨床重要。單一研究不代表共識，搜尋後續重複、系統回顧及指南，注意族群與時間適用性。不因小樣本直接判假，也不憑摘要完成方法審查。

scripts.scientific_analyzer.review_status只標記metadata風險與待審狀態，不會審論文。撤稿證據不作實質支持；更正後重新讀修正版、追蹤結論變更，不自動判整篇為假。缺全文清楚列無法檢查事項。醫療／安全主張提供證據和限制，不替個人診斷。
