# 論證與操弄分析
事實準確性與論證品質分開記錄。對每項問題保存：原句、推論、為何不成立、缺的證據、更精確版本。不要只貼謬誤名稱，不以情緒字眼判假。

- 選擇性引用／選擇時間窗：補查被省略年份、對照組和相反結果。
- 錯誤因果／相關當因果：檢查先後、對照、反向因果與混雜。
- 錯誤等同／誤導比較：先核定義、期間、母體、測量與資源條件。
- 倖存者偏差／不具代表樣本：查抽樣框與失敗／失訪資料。
- 不當權威訴求：確認專業範圍及原始研究，不把權威身分當證據本身。
- 忽視基準率：列母體和絕對風險，再列相對變化。
- 以偏概全：把結論限制在實際樣本與適用條件。
- 上下文省略／誤導圖表：取完整段落、圖軸及資料表，比對省略是否改變結論。

採用公開研究與抄襲是不同命題，需分開核授權、引用、內容及時間，不因相似就指控不當行為。
