# 圖片與影片脈絡
把「是否為某事件」與「是否經過編輯」拆開查。保存檔案hash、可得EXIF、發布頁與說明、最早可找到的版本；最早找到不等於真正首次發布。下載與解碼受大小／時間限制，不執行附件程式，不自動啟動影片解碼器。

本版scripts.media_checker.inspect只做本機檔案hash、可選Pillow基本metadata與EXIF；不會鑑真。Pillow未安裝正常降級。OCR、影片關鍵影格、反向圖片搜尋及公共網頁存檔需宿主工具；沒有就明示未執行。

比對公共地標、季節、日期、完整畫面、原始字幕與音軌、裁切、翻譯、浮水印及發布脈絡。列出精確可見與不可確認處。EXIF可被改寫或移除，不存在不代表造假；單一AI偵測器或ELA不能確證合成。不得僅以視覺直覺宣稱AI生成。

同影像較早公開只反駁「此次首次拍攝」等時間命題，不能自動證明完整事件解釋。缺來源時UNVERIFIED。不得追蹤私人位置、識別無公共利益私人身分或無根據指控犯罪。
