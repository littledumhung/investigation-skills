# 判定與反證
TRUE：充分直接支持。MOSTLY_TRUE：核心支持，限制不改核心。MIXED：具實質正反部分或重大成立條件；可拆則先拆。MISLEADING：數字／陳述可能正確，但比較、脈絡、推論導致錯誤印象。FALSE：明確反駁，不能只因無證據。OUTDATED：有曾成立與後來變更證據。UNVERIFIED：證據不足、矛盾未解或工具受限。NOT_CHECKABLE：意見、價值或無法明確驗證的表述。

每項列最強支持與反證、來源品質、限制、HIGH/MEDIUM/LOW及checked_at。信心不是正確機率。高品質直接資料可勝過多篇轉載；不以立場或來源知名度代替內容。

結論前先寫初判、關鍵前提和可能推翻條件，再做至少一項相關反證搜尋。搜尋範圍與失敗也入紀錄；NONE_FOUND不表示不存在反證；BLOCKED不能偽裝搜尋成功。對矛盾檢查年份、定義、口徑、版本、獨立性，必要時修正並保存reason。

verdict_engine.recommend僅依agent提供的判讀旗標做保守建議，不解讀原文，不輸出校準分數。validate拒絕無證據的實質判定、錯配claim與evidence、撤稿／不可存取來源作支持、查核基準之後的證據。仍需agent檢查證據實際含義。
