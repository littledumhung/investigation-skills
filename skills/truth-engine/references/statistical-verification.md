# 數據與統計查核
先記來源表格位置、原始數字、單位、幣別、名目／實質價格、母體、期間、會計年度與事業範圍。不要把單季和全年、不同幣別或不同母體直接當成成長率；缺口徑標UNKNOWN。用 scripts.statistics_engine.compare_context 對照，不會自動把UNKNOWN當MATCH。

calculate 支援 percent_change、cagr、mean、median、proportion、risk_ratio、risk_difference。提供sources、unit、assumptions，保存原值、公式、結果與ROUND_HALF_UP規則；報告驗證會重算。percent_change要求正基期，負或零基期改寫絕對差並說明，不產生無意義成長率。風險比2倍可能只是1%到2%；風險差是1百分點，兩者都列。

平均不代表分布；中位數不代表所有人。檢查分母、樣本數、抽樣方法與分組，留意辛普森悖論、基期與季節性。CAGR只描述首尾，不表示每年同速。匯率和通膨調整要有來源及日期。

圖表逐項記錄軸起點、單位、對數刻度、雙軸、缺資料、區間、截斷與面積效果。截斷軸不自動等於造假，說明它如何改變感受。圖像讀值標估算，不當精確原值。本版不自動解讀圖表，交由agent和可用視覺工具。

無原始資料不重建p值、統計檢定、樣本量充分性或信賴區間。相關資料不證明因果；樣本數不足的結論須依設計及效果不確定性，不單看門檻。
