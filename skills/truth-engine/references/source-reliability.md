# 來源可靠性、溯源與去重

每個 Source 保存 ID、原始 URL、正規 URL、標題、作者／機構、發布、更新、存取日期、文件版本、可存取狀態、定位、原始內容位置、第一手標記、引用對象、更正／撤稿狀態。日期未知填 null 並註原因；只抓到 metadata 必須註明。

角色採 PRIMARY、SECONDARY、TERTIARY、REPOST、MIRROR、UNKNOWN。角色是相對命題：公司新聞稿是「公司發布宣稱」的第一手來源，不必然是「產品有效」的獨立證據。

## 追溯

沿引用到原始文件或數據，記錄每一步 QUOTES／DERIVED_FROM。追不到時寫停止在何文件、何原因及下一步。轉載、鏡像、同一通訊社稿件歸同一來源家族；不同網址、不同標題、不同語言不代表獨立。引用同一數據但有獨立分析，區別數據獨立性與分析獨立性。

URL 正規化不可盲刪具語義 query；內容 hash 可找完全複本，但不能判定語義等價。模糊比對只是候選，agent 檢視後才合併。矛盾數字先對比版本、期間、定義、修訂與來源家族。

## 品質敘述

就每項證據評估直接性、可稽核性、方法、利益衝突、版本狀態及適用範圍，不用固定品牌分數代替判讀。明示原始來源也可能錯誤。無法存取只能引用已取得的範圍，禁止用二手摘要補出假引文。

分開畫來源相依圖（誰引用誰）與主張證據圖（何項支持／反駁何項）。反證搜尋記錄初判、關鍵前提、反向查詢、候選與結果、修正理由；沒有反證也須寫搜尋範圍，不能說已證明不存在反證。
