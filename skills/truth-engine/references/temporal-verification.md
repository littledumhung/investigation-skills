# 時間與版本

逐項固定 as_of 日期與時區；「現在」採實際查核時間，輸出 ISO 8601（可得時含時區）。只有日期時保留日期精度，不能補 00:00 當實際時刻。

分別記錄事件、發言、資料蒐集、發布、網頁更新、查核、法規生效與失效時間。頁尾版權年份不是發布日期；抓取時間不是事件日期。來源缺日期填 null／unknown 原因。OCR 看出的日期先標候選。

以 as-of 作歷史查核時，區分「當時可取得的證據」與「事後回看發生何事」；後來發布資料可作回溯證據，但不得稱當時已知。網頁新版本不能覆蓋歷史版；存版本 URL、修訂關係及擷取狀態。

OUTDATED 需舊時點確實成立的證據，及新時點已改變的證據。只有一篇舊文章、沒有當前資料時是 UNVERIFIED（目前狀態），不是自動 OUTDATED。法律另核司法管轄、生效、修法、過渡條款；法律文件不可僅憑發布日判有效。

## 期間可比性

公司財年不等於曆年，單季不等於全年。流量數值對相同期間；存量比相同時點；調整後數值與原值分列。必要時用同時區與相同結算基礎重新計算。不能只因日期格式可解析就宣稱時間已驗證。

時效資料網路不可用時，寫「截至所提供版本」與缺少什麼新資料，不聲稱完成最新查證。
