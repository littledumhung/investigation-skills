# 時間推理

保存原始時間文字、轉換規則及錨定日期。相對日期用使用者當地日期；CLI --today 可讓結果可重現。

- `2010–2015` 是明示區間；`2009 年以前` 按嚴格語義為 ≤2008，若使用者可能含 2009 就確認。
- `2012 左右` 預設推定 2010–2014；`十年前` 推定錨定年−12 至−8；`十幾年前` 為−19 至−11。這些都是搜尋提示，不是確定事實。
- XP 時代暫以 2001–2014、Flash 暫以 1996–2020 為粗略提示；產品生命週期不等於使用者停止使用的日期。
- 不懂的日期語句回傳 null，不臆測。Agent 可處理更複雜的自然語言並明記推定。

日期欄位必須分開：captured_at（快照）、content_timestamp（內容聲稱的發布時間）、published_at（發行紀錄）、indexed_at（索引；未取得為 null）、claimed_at（使用者聲稱）、inferred_range（推定）。不能用 snapshot 日期填 content_timestamp。

Wayback timestamp 是 UTC；一般原始頁面日期可能未知時區。不同時區不確定時保留原表示法。相鄰快照只能把改版時間界定在二者之間；CSS／圖片／第三方嵌入資源可能來自不同年代。404 可以是當時真的 404，也可以是重播失敗，分開保存索引 HTTP 狀態及目前抓取狀態。

快照排序只能得出「本次範圍／限額內最早可查」，不能說網站成立、軟體首版或媒體原始發布時間。若要關站時間，找官方公告並用最後活動／最早停站快照建立界限。API 抽樣或分頁未取完應在時間軸註記不完整。
