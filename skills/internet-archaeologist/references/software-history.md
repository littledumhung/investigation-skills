# 軟體歷史調查

從名稱、功能、檔名、副檔名、作者、OS、UI 特徵建立候選。查中英日別名、README、changelog、官方下載頁、tags/releases、套件註冊庫與公開論壇。GitHub created_at 是 repository 建立時間；移入 GitHub 的歷史程式可能更早。

記錄原名、開發者／公司、官方歷史網站、第一個**有證據**版本、最後**已知**版本、發布日期、平台、license/open-source 證據、仍可用的官方下載、原始碼、替代工具。未取完所有版本就不能把近期三頁結果稱為最後或最早版本。prerelease 與穩定版分開，不按 tag 字串字典順序推定語意版本順序。

作者已消失只剩轉載時，記錄「第三方引用」，沿原始連結查存檔，保留未確認欄位。收購公告、歷史重導向、連續 commit SHA 才能支持公司／專案延續；同名 repo 不足。

所有歷史可執行檔預設 untrusted。不自動下載或執行；只列識別資訊與必要風險提示。優先官方來源、原始發布的 SHA-256、平台數位簽章。即使雜湊符合也只是完整性，不是安全保證；不能建議停用防毒。若使用者另行要求處理檔案，需另定下載範圍且禁止執行，將來源／hash／簽章／驗證狀態分開記錄。
