# 模糊遊戲記憶

把故事拆成可檢驗特徵：大約玩過年份、瀏覽器／Flash／Java／桌面／手機／主機、2D/3D、側視／俯視、角色形狀與顏色、移動方式、核心機制、畫面風格、音樂、特殊關卡、入口網站及語言。

記憶可能混合不同作品，先保留假設，不把藍方塊、極簡畫面等一般特徵當作唯一識別。問最能區分候選的一件事，例如「角色是自己跳還是由滑鼠移動平台？」

Agent 提出至少可合理支持的候選（不足則不硬湊數量），表列：name、aliases、release_year、developer、platform、mechanics、visual_features、matching_clues、contradicting_clues、source_urls、availability、identity_label。中英日名稱必須由來源證實對應，不是將名稱翻譯後就當官方別名。

搜尋發布者舊網站、遊戲入口網快照、當年評測／論壇、開發者影片、縮圖檔名、Archive.org 公開紀錄。Flashpoint／Ruffle 等合法保存與相容方案是研究方向；先確認條目與授權，不自動下載或執行 SWF。截圖用宿主圖片理解或 OCR 擷取可見字、比例與 UI；沒有工具則要求文字描述，不假裝反向搜圖。

重大年代矛盾阻止確認，但「回顧文章 2020 年」並不否定「2010 年已玩過」。區分資料記錄時間與作品發布時間。最終呈現相似及不同之處，找不到原始畫面時說明這是尚未驗證的候選。
