# 來源可靠性與獨立性

優先：當時官方頁面／發布公告／版本庫與數位簽章，其次同時代獨立報導／社群引用，再其次後來回顧及搜尋摘要。官方也會錯；保留矛盾，不以機械加分代替判讀。

為每個斷言記錄原始來源、擷取時間、發布時間（若有）、原文短摘或特徵、限制。引用只保留支持所需內容，不大段複製版權文本。搜尋摘要、Wiki 及 Archive.org catalog 是發現線索的工具，不能單獨當原始內容已找回。

判斷獨立性先看引用鏈及高度相同措辭。十個鏡像抄同一篇文章只算一個 origin；若未知是否獨立，不能當多源交叉驗證。取得 HTML 的 SHA-256 與 CDX digest 是不同雜湊，不混用。

可信度高：直接身分／內容證據獲獨立交叉支持且無重大矛盾；中：有明確支持但缺直證或尚有缺口；低：只有間接提及；無法判定：缺證或重大矛盾。這些是研究信心，不是統計機率。

「原始內容」「可信鏡像」「歷史紀錄」「文字提及」「證據不足」分開標記。鏡像需驗證發布者、內容及 hash／官方連結等依據；不要因能播放或同名就稱可信。
