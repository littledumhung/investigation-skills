# 證據排序規則

| kind | 分數 | 用途 |
|---|---:|---|
| direct | +5 | 直接對上來源中的特徵或可核實明文 |
| strong | +3 | 能區分候選的獨立旁證 |
| weak | +1 | 風格、氣候、模糊 OCR 等 |
| contradiction | -6 | 與預測特徵或年代衝突 |
| missing | 0 | 尚未取得，不可當反證 |

uncertain 的正向證據最多 +1。每個 independence_group 只取最大正分與最小負分之和，避免鏡像轉載灌分；未標記譜系者全部放 unverified-lineage，不能滿足獨立強來源數。不同網域不自動代表不同來源，Agent 要讀原文確認是否互抄，同源者填同一組。

低：淨分 > 0。中：≥5、至少兩組獨立強證據、無矛盾。高：≥8、至少兩組獨立強證據、含確定直接證據、做過反證、無矛盾、unverified 為空。其餘無法判定。以上僅啟發式，不是統計機率。

反證紀錄只證明有記錄，程式無法驗證 Agent 是否誠實搜尋。Evidence bundle 不是可信簽章，來源真實性與譜系仍需人工或 Agent 審閱。重要結論附具體來源，不用分數取代解釋。

可透過 rank_candidates(..., weights={...}) 調整五類分數；預設可信門檻配合預設分數，改分數時應一併檢視門檻，勿稱模型校準。
