# 公開場景定位

依序縮小國家→區域→城市→行政區→街道→拍攝位置。每層可以保持多個分支，語言、氣候、建築風格僅作弱旁證。

先做線索表：招牌原文與備選讀法、路口拓撲、標誌制度、行車側、公共運輸、山稜／岸線。車牌只能使用制度外觀，避免收錄私人車牌號碼。

針對候選查官方地標介紹、地圖 POI、道路配置及來源日期；查同名異地。幾何驗證最少比較兩種不同特徵：例如建築相對位置＋道路轉角，而非同一招牌顏色兩次。

街景紀錄表：source_url、source_date、camera_lat/lon、heading、pitch/fov（工具提供時）、道路側、前景／背景、左右順序、遮擋、改建差異、剩餘疑點。沒取得日期就填 unknown。陰影僅輔助，不得單獨推導精確座標。

座標必須帶 role：poi_center／building_center／camera_position／estimated_photo_position。估計位置須有誤差範圍或明確文字限制；不能將地圖中心誤作拍攝點。若僅證明地標，結論只到地標。

定位遊戲／測驗可輸出住宅街景、鄉村及一般道路的拍攝點；不要求先辨識公共建築或證明地點可進入。已驗證點與估計點分開標示，不能以遊戲名義追蹤特定個人。EXIF 不能代替視覺查證。CLI 可匯入候選座標並產生地圖連結。
